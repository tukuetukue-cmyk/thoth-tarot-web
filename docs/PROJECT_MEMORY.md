# PROJECT_MEMORY.md

## プロジェクトの永続的記憶 (フロントエンド)

このファイルは **Codex** へ引き継ぐ際に、Webリポジトリ全体の重要情報・前提条件・設定値を一元管理するためのメモリです。

### 1. Firebase 関連設定
- 本番のホスティングは Firebase Hosting (`public/` ディレクトリ公開)。
- プロジェクトID は `.firebaserc` に `cinnamonclove-7be76` として記録されています。
- `firebase.json` が実在し、公開設定やリライト設定が定義されています。
- Firebase Authentication, Firestore, Premium関連機能は、ソースコード上に存在しますが、現状は **未完成または休眠状態** です。
- 実装上の Firebase `apiKey` はプレースホルダーのままであり、参照先 DOM 要素や変数に不整合が残っていることが既知事項として認識されています。

### 2. クライアント側の仕様と制限
- **1日3回の制限**: 制限の判定はサーバーサイド（ユーザーアカウント）ではなく、ブラウザの `localStorage` 単位で管理されています。
- **localhost でのバイパス**: 実行環境が `localhost` の場合、**この回数制限のみが無効化** されます。
- **API接続先**:
  - リーディング / チャット / 振り返り: `localhost` 環境でも、常に本番API (`https://thoth-tarot-api.onrender.com`) へ接続します。
  - 霊的カルテ: `localhost` 環境時のみローカルAPI (`http://localhost:8000`) へ接続します。
- **デバッグ仕様**: クエリーパラメーター `force_card` を使用した強制カード表示は、本番環境でも利用可能な既知の仕様です。
- **多言語対応**: 日本語/英語の切り替えは完全ではなく、動的な結果や一部の画面では即時反映されない既知の不具合があります。
- **3枚引き**: 3枚引きのロジックはコード上に存在しますが、通常のUI上では非表示となっています。

### 3. デザイン・仕様における既知の不整合 (要エクツ確認)
- **商用リンク**: Ko-fiなどの商用リンクについて、「永久に削除する」という方針と、「一時的にコメントアウトで非表示にする」という記述が衝突しています。
- **絵文字の扱い**: ドキュメント上ではサイト全体の絵文字使用を禁止していますが、実装内には可視の絵文字がいくつか残存しています。
- 上記はどちらが正しい仕様であるかを推測で決めず、将来的に確認が必要です。

### 4. セキュリティ上の要対応事項 (コード修正は行わず文書化のみ)
以下のセキュリティリスクは既知事項として文書化されています。
- **DOM XSS リスク**: `innerHTML` に対してユーザー入力やAIからの出力結果を直接挿入している箇所があります。
- **クライアント依存の制限**: 鑑定回数の制限がクライアントサイド (`localStorage`) に依存しており、回避が容易です。
- **API認証の不在**: API 呼び出し時にトークンやAPIキーを用いた認証が行われていません。
- **ヘッダー未整備**: CSP (Content Security Policy)、SRI、その他のセキュリティヘッダーが未整備です。
- **機密情報の保存**: `localStorage` に名前、生年月日、相談内容、AIのリーディング結果が平文で保存されています。
- **リクエスト制御**: ネットワークリクエストのタイムアウト処理、`AbortController` によるキャンセル、およびボタン連打による多重送信対策が実装されていません。
