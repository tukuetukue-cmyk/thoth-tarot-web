# DESIGN.md - UI/UX デザイン仕様書

## 使用カラーと用途
- `--bg-color` (背景色): #0b0c10 – ダークな全体背景。
- `--card-bg` (カード背景): rgba(26, 26, 36, 0.7) – ガラスモーフィズムの半透明カード。
- `--glass-border` (ガラス境界線): rgba(255, 255, 255, 0.1) – カード・モーダル等の境界線。
- `--text-primary` (主要テキスト): #e0e2e4 – 明るい本文テキスト。
- `--text-secondary` (補助テキスト): #a0a5b0 – 補足情報やサブタイトル。
- `--accent-gold` (アクセント色): #d4af37 – ロゴ、ボタン、リンクなどの重要要素。
- `--accent-gold-hover`: #f1c40f – ゴールド系ホバー時の色変化。
- `--accent-purple`: #4a235a – ボタン背景のグラデーションに使用。

## フォントとタイポグラフィ
- **ヘッダー・見出し系**: `Julius Sans One` (Google Fonts)
- **本文・長文**: `Noto Serif JP` (セリフ体)
- **補助ラベル・入力**: `Noto Sans JP` (サンセリフ体)
- ロゴテキスト: 2.5rem, ゴールドカラー, テキストシャドウあり
- 見出し (`h2` 等): 1.5rem〜2.5rem, アクセントゴールド
- ボタンテキスト: 1.2rem〜1.5rem, 文字間 1px

## 主要画面の UI 仕様

### 1. メイン画面 (リーディング)
- `.glass-container` を用いたガラスモーフィズム (背景ぼかし `backdrop-filter: blur(12px)`)
- 背景は `particles.js` による星空エフェクトと `radial-gradient`
- アニメーション: `fadeIn` (不透明度+上方向移動)、`spin` (ローディングリング)
- ボタン全般に `transition: all 0.3s ease` によるホバー変化 (色変化、シャドウ拡大、微小な上昇)
- 通常UIでは3枚引き用のコードが存在するものの非表示

### 2. 生命の樹 (セフィロト) UI
- SVG ベースのインタラクティブな描画
- セフィラ（球）内の日本語名表示を排除し、番号と英語名のみのミニマルデザイン
- パスの当たり判定: 見える細い線の裏に透明な太い線を重ねることで、モバイルタップ時の操作性を向上させる（インビジブル・ヒットボックス）
- 各セフィラとパスはアクセントゴールドを基調とし、神秘的な雰囲気を維持

### 3. 霊的カルテ (Spiritual Report)
- 長文テキストを `Noto Serif JP` で読みやすくレイアウト
- 象徴（シンボル）の解説機能として、特定のキーワードクリックでモーダル等による学習UIを展開
- スクロールに連動し、関連するキーワード（英語・日本語）がハイライトされる機能
- 結果カードは柔らかなシャドウとフェードインアニメーションで表示

## レスポンシブ対応とモバイル
- 最大幅 768px: ボタン類の縮小
- 最大幅 600px: フォーム等の2列レイアウトを1列レイアウトへ変更
- モバイル時でもアニメーション・トランジションやグラスモーフィズムは同様に適用
