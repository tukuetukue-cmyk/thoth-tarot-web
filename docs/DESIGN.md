# DESIGN.md - UI/UX デザイン仕様書

## 使用カラーと用途
- `--bg-color` (背景色): #0b0c10 – ダークな全体背景。
- `--card-bg` (カード背景): rgba(26, 26, 36, 0.7) – ガラスモーフィズムの半透明カード。
- `--glass-border` (ガラス境界線): rgba(255, 255, 255, 0.1) – カード・モーダル等の境界線。
- `--text-primary` (主要テキスト): #e0e2e4 – 明るい本文テキスト。
- `--text-secondary` (補助テキスト): #a0a5b0 – 補足情報やサブタイトル。
- `--accent-gold` (アクセント色): #d4af37 – ロゴ、ボタン、リンクなどの重要要素。
- `--accent-gold-hover`: #f1c40f – ゴールド系ホバー時の色変化。
- `--accent-purple`: #4a235a – ボタン背景のグラデーションに使用。
- `--premium-gold` / `--deep-gold`: プレミアム要素向けの金色バリエーション（未確認）。

## フォント
- **ヘッダー・見出し系**: `Julius Sans One`（Google Fonts） → `var(--font-heading)`
- **本文・長文**: `Noto Serif JP`（セリフ体） → `var(--font-body)`
- **補助ラベル・入力**: `Noto Sans JP`（サンセリフ） → 直接指定されている箇所あり。
- フォントはすべて `font-family` カスタムプロパティで管理され、`index.html` でロード。

## タイポグラフィ
- ロゴテキスト: 2.5rem、文字間 0.1em、ゴールドカラー、テキストシャドウあり。
- サブタイトル: 1rem、文字間 2px、補助テキストカラー。
- 見出し (`h2` 等): `var(--font-heading)`、サイズ 1.5rem〜2.5rem、カラーはアクセントゴールド。
- ラベル: `var(--font-heading)`、サイズ 1.1rem、カラーアクセントゴールド。
- 入力フィールド: `var(--font-body)`、フォントサイズ 1rem、プレースホルダーは未指定（デフォルト）。
- ボタンテキスト: `var(--font-heading)`、サイズ 1.2rem〜1.5rem、文字間 1px。
- カードタイトル・カード名（英語/日本語）: `var(--font-heading)` と `Noto Sans JP` の組み合わせ、サイズ 2.2rem / 0.95em など。

## 背景
- `particles-bg` コンテナに固定配置し、`radial-gradient(circle at center, #1b1c2b 0%, #0b0c10 100%)` を使用。
- ページ全体は `--bg-color` のダーク色で塗りつぶし、`particles.js` による星空エフェクトが重ねられる。

## ボタンデザイン
- **.mystic-btn**: グラデーション背景 (accent-purple → #2c1630)、ゴールド文字、ボーダー、丸角 30px、シャドウ、ホバーで色・シャドウ変化、少し上昇するトランスフォーム。
- **.report-notice-btn**: 半透明黒背景、ゴールドボーダー、ホバーで暗い紫背景とゴールドホバー、ボックスシャドウ、柔らかいトランジション。
- **.transparent-btn**: 透明背景、ゴールド枠線、ホバーで薄いゴールドの背景とシャドウ。
- **.premium-mosh-btn**: ゴールド系をアクセントにした線形グラデーション、内部シャドウ、ホバーで色相変化と拡大トランスフォーム。
- ボタン全般に `transition: all 0.3s ease` が設定され、ユーザーインタラクション感を強調。

## カード UI / リーディング結果
- `.glass-container` がページのメインラッパーで、`backdrop-filter: blur(12px)` と半透明背景でガラスモーフィズム実装。
- カード画像 (`.tarot-card-img`) は 250px 最大、金色枠、ホバーで 1.05 倍に拡大。
- カード情報エリアはゴールドタイトル、セリフ体日本語名、サブテキストは補助カラー。
- 結果カードはフェードインアニメーション、柔らかなシャドウ。

## グラスモーフィズム
- `backdrop-filter: blur(12px)` と `background: var(--card-bg)` を組み合わせ、ガラス感を実現。
- ボーダーは `var(--glass-border)` の薄い白で、丸角 20px、シャドウで浮き上がり感。
- モーダル (`.modal-overlay`) でも同様に `backdrop-filter: blur(5px)` が使用され、背景暗転とぼかしが適用。

## 余白・レイアウト
- メインコンテナのマージン: 2rem 上下自動センタリング、パディング 3rem 2rem。
- Flex と Grid を組み合わせ、入力セクションは `display: flex; flex-direction: column; gap: 1.5rem`。
- `.user-details-inputs` は 2 列グリッド（600px 以下で 1 列へ切り替え）。
- ボタンはブロックレベルでセンタリング、幅 250px で統一。
- フッターは上部境界線、シンプルなセンタリング。

## レスポンシブ対応
- **最大幅 768px**: `.report-notice-btn` のフォントサイズ・パディング縮小、幅 90%。
- **最大幅 600px**: `.user-details-inputs` が 1 列レイアウトへ変更。
- それ以外の要素は柔軟な `flex` / `grid` による自動調整。

## アニメーション・トランジション
- `fadeIn` (opacity+translateY) と `slideInFromBottom`、`spin`（ローディングスピナー）を使用。
- ほぼ全要素に `transition: all 0.3s ease` が設定され、ホバー時のスムーズな変化を実現。
- ローディングスピナーは二重リングで 1.5s/1s の回転。

## ホバー / フォーカス状態
- ボタン・リンクはカラー変化、シャドウ拡大、微細な `transform: translateY(-2px)` で立ち上がり感。
- `.spread-option` ラジオボタン選択時は背景色が紫系に変化し、ゴールド文字に。
- 入力フィールドはフォーカスでボーダーが `var(--accent-gold)`、背景濃さが増し、シャドウが付与。
- カード画像はホバーでスケールアップ。

## モーダル・ダイアログ
- `.modal-overlay` が全画面固定、暗黒背景 + `backdrop-filter: blur(5px)`、センタリング。
- コンテンツは `.glass-card`（未確認）でガラスモーフィズムが適用される想定。
- `.history-modal`, `.symbol-modal` などは同様のスタイルを継承。

## モバイル時の挙動
- 入力フォームは 1 列レイアウトに切り替わり、パディング・フォントサイズが若干縮小。
- ボタンは幅 90% に自動調整し、タップしやすいサイズを維持。
- メインコンテナは横幅 100% で画面にフィット。
- アニメーション・トランジションはモバイルでも同様に適用。

## デザイン変更時に維持すべき特徴
- **ダークモードベースの配色**（黒・ダークグレー）と **ゴールドアクセント**。
- **ガラスモーフィズム**（blur + 半透明背景 + 薄い白枠）。
- **丸みある UI**（ボタン丸角 30px、カード境界 20px、モーダル丸角）。
- **微細なマイクロアニメーション**（フェードイン、スピン、ホバー時のトランスフォーム）。
- **カスタムフォント** (`Julius Sans One`, `Noto Serif JP`, `Noto Sans JP`) の一貫使用。
- **アクセントゴールド** を全 UI のハイライトに使用し続けること。
